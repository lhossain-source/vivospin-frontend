# Gemini AI Agent for iPhone-first development

This repository includes a GitHub Actions agent that can prepare code changes and review pull requests from the GitHub mobile app.

## One-time setup

1. Open **Settings → Secrets and variables → Actions → New repository secret**.
2. Set the secret name to `GEMINI_API_KEY` and paste your Google AI Studio API key. Never put the key in an Issue, source file, or commit.
3. In **Settings → Actions → General → Workflow permissions**, allow the workflow to read and write repository contents and pull requests. The workflow declares its own limited permissions; organization policy may override them.
4. Ensure Actions are enabled. The agent uses Gemini 2.5 Flash through Google's Generative Language API.

## Trigger tasks from your iPhone

- Create an Issue with a clear title and detailed acceptance criteria. Include `@agent`, `/fix`, or the `ai-agent` label in the title/body to request implementation.
- Or comment on an existing non-PR Issue: `@agent please fix the mobile layout overlap and add a regression test`.
- For review, open or update a Pull Request. The workflow posts a Gemini review comment.
- Check **Actions** in the GitHub app to see logs and failures.

## Safety and merge behavior

- Issue tasks are processed from `main`; Gemini returns a unified diff, which is validated with `git apply --check`.
- Changes are committed to a separate `ai-agent/*` branch and opened as a Pull Request. The agent does **not** push unreviewed generated code directly to `main`.
- When a repository collaborator submits an **APPROVE** review on an `ai-agent/*` PR, the workflow attempts a squash merge to `main`. GitHub branch protection and required checks still apply; configure them in repository settings.
- Do not approve a PR until you have reviewed the diff and checks. Model-generated changes can be wrong.
- The agent does not run code generated by Gemini. Fork-originated pull requests are excluded from the review job to avoid exposing secrets.
- The Issue workflow is intentionally gated by `@agent`, `/fix`, or `ai-agent`; merely opening every ordinary Issue does not cause code changes.
